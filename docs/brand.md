# VECTOR Assessment Engine — Brand

UST colours across welcome, assessment, report, and admin. The old navy/gold prototype palette is retired.

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| UST dark teal | `#006E74` | Bars, buttons, headings, build banner |
| UST light teal | `#0097AC` | Accents, links, secondary highlights |
| UST teal deep | `#004F54` | Report header, assessment chrome |
| UST soft black | `#231F20` | Body text |
| UST off-white | `#EEF6F7` | Page backgrounds |
| White | `#FFFFFF` | Cards, inputs, report body |
| Signal green | `#0a9b72` | Positive admin actions |
| Signal coral | `#e0604a` | Errors |

If a tester still sees a gold bar or navy page, they are on an old build.

## Type

- Body / UI: Source Sans 3
- Display / report class and sign: Source Serif 4
- Codes / meta: DM Mono

VECTOR CLASS and VECTOR SIGN use the same large serif size. Interpretation sits beside the sign.
